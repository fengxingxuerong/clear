  趣AI味 · QuAiWei v0.9.14 桌面版（Windows）使用说明
══════════════════════════════════════════════════════

【这是什么】
把 AI 写的文章改得更像人写的，改完就地检测"AI 味"还剩多少。
默认不配置任何 API 也能用（本地引擎离线运行、零成本）。

【怎么跑】
双击本目录下的 QuAiWei.exe 即可，无需安装、无需 Node 环境。

【三个核心按钮】
  去味    —— 把左侧原文改成人写感；默认开 8 稿择优（多候选择优）。
  AI 检测 —— 16 特征本地三档判定，原文与去味稿降档对照。
  朱雀检测 —— 对齐腾讯朱雀口径的本地近似：三档占比、句级红黄标注、
             12+1 维特征、体裁线预测、语义层（需 API）、校准回填。

【LLM 增强（可选但推荐）】
⚠️ 本桌面版**不内置任何 API Key**（v0.8.6 起 Key 已全部移出源码，见下方【隐私】）。
设置 → 自己填 Base URL / API Key / 模型，任意 OpenAI 兼容服务商皆可。
  · 设置里那个「填入 SenseNova 常驻通道」按钮是**给开发者本机用的**：它要求环境变量
    SENSENOVA_KEYS 或工作目录下的 scripts/.sensenova-keys 里有 Key。桌面版两个都没有，
    所以按钮会显示「（未配置 Key）」并置灰——这不是故障，请手动填 Key。
  · 用 SenseNova 时可参考：Base URL 填 /sensenova/v1（桌面版已内置网关转发，不用自备反代），
    模型 deepseek-v4-flash（主力）/ deepseek-v4-pro（备选）/ glm-5.2（交叉评判）。
  · 填了之后「去味」自动走深度闭环（改写→评分→质检→定向修订，最多 4 轮）。

【v0.9.14 起深度模式的三条行为变化】
  · 首轮评判分就落进"人写带"（≤28）时不再开修订轮——实测两轮修订都没拿到更优分，
    继续追只是白烧调用；绝对达标线（默认 10 分）没有放宽。
  · 设置里的「严格保真」默认关闭。开启后交付前会对最终稿再做一次独立事实核查，
    发现编造即**拒绝交付**并回退本地引擎。注意核查本身有漏判率，不担保干净。
  · 「最长等待」是**软上限**：它只在轮与轮之间、每个候选开跑前检查，当前候选会跑完，
    最坏可超上限约 2~4 分钟。收稿前的安全核查不受该时限取消。

【朱雀送检与校准（攒官方真值）】
朱雀没有公开 API，官方结果只能走网页：
  1. 朱雀检测面板 →「复制送检文本」→「打开朱雀官网」粘贴检测（≥350 字）；
  2. 把官方结果（如「AI生成 99.99%」）粘回面板 →「记为校准点」；
  3. 或开「校准实验室」批量生成样本逐条回填；
  4. 攒到 4 条出官方分估计，8 条启用留出验证。
桌面版已预置样本 D 两点官方真值锚点（99.99% / 98.47%）。
⚠️ 这两点同时参与拟合，属于自证；换算线只可当粗略参考，不是官方分预报。

【别用界面分数判断能不能过检】
内置「AI 检测」与去味引擎共用一套词表，去味后自带分必然变好看——这是同一把尺子在量自己。
判断是否安全请以真实检测器（朱雀网页版）的结果为准，不要看界面上的降幅。

【隐私与密钥存储】
所有配置、历史、校准数据只存本机，不上传任何文本。
API Key（含多 Key 池）经系统级加密（safeStorage）存到 userData/secure-config.json，
**不写进 localStorage 明文**。
  · 若从 v0.9.14 之前的桌面版升级过来：老版本曾把「Key 池」明文留在 localStorage 里，
    本版本启动时会自动把它搬进加密存储并抹掉明文副本，无需手动处理。
  · 极少数情况下系统加密不可用（Windows 上基本不会遇到），此时程序**不会**为了"看起来安全"
    而抹掉你的 Key，而是退回明文保存 —— 用完建议在设置里清空 Key 一栏。

【故障排查】
  · 窗口空白：本目录是便携版，别把 exe 单独拷出去跑，整目录一起拷；
  · LLM 报错 429：Key 池自动轮换重试，稍候即可；仍失败自动回退本地引擎；
  · 「填入 SenseNova 常驻通道」点不动：见上文【LLM 增强】，桌面版本就不带 Key；
  · 首次「指纹体检」第 8 项要下载约 100MB 困惑度模型，之后全离线。
