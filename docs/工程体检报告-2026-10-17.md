### 1.3 已修复：`App.test.tsx` 与 `app-smoke.test.tsx` 的重复

两个文件都在**默认视图档**渲染整棵树，重复了 3 条断言；另有一条整条重复：

- `App.test.tsx`「主界面」的 标题 / 原文 placeholder / 去味按钮 三条 → 与 `app-smoke`「整棵树挂载」逐字重复。
  现只保留 `app-smoke` 没覆盖的两条（输出区 placeholder、强度滑块 range），describe 改名并加注释指路。
- `App.test.tsx`「「清空」按钮：清空输入并丢弃草稿」→ 与 `app-smoke`「「清空」按钮清空输入输出」重复，

## 6. 方法论沉淀（写进项目约定）

1. **重名用例 ≠ 重复用例**。9 组重名里只有 1 组是真重复（同 describe 内），其余 8 组是
   不同被测函数的巧合同名 → 消歧即可，删了就是丢覆盖。
2. **去重前先看「谁更强」**。`App.test.tsx` 的「清空」用例名承诺了「丢弃草稿」却没有对应断言，
   而 `app-smoke` 那条更强 → 删弱留强，不是反过来。
3. **整块字符串替换，别按行号 splice**。行号在多次编辑后会漂移（本次第一次按行号删，
   净行数变化导致删错了相邻用例，已 `git checkout` 还原重做）。
4. 清理前先分清「gitignore 的临时产物」和「仓库内的文件」——前者可直删，后者要留 git 回溯路径。
