## 改动（src/engine/humanize.ts，git diff +~90 行）

### 1. softenPassive（新函数，replaceVocab 之前）
被动固定搭配白名单替换：
- 被广泛使用于X → 在X用得很广 / 在X到处都在用
- 受到广泛关注 → 大家都很关注 / 被不少人盯着看 / 挺受看重
- 得到广泛认可 → 大家都很认可 / 口碑不错 / 普遍叫好
- 被认为是 → 大家普遍觉得是（保留"是"）
- 被称之为 → 大家管它叫 / 人称 / 俗称

### 2. frontAdverbial（新函数，reframeConcessives 之后）
状语前置，白名单主语（20 词）+ 在/于 + 处所 + 中/上/里 + 动词 → "在X中，主语+动词"。

### 3. GUARD_BEFORE + replaceVocab 特判
- 关注/重视 加守卫 ["受到","得到","予以"]
- 关注/重视 的守卫窗口特判扩到 6 字（"受到了广泛"里"受到"离词 4 字），其他词保持 3 字

## 关键踩坑
1. **frontAdverbial 初版切词 bug**：通用正则捕获主语边界把"人工智能技术"切成"技/术"→"人工智能技在医疗诊断领域中，术被广泛应用"。白名单主语方案根治。
2. **调用顺序**：softenPassive 必须在 replaceVocab 之前，否则"受到广泛关注"已被 VOCAB 替身"盯着"破坏，匹配不到。
3. **"被认为是"丢"是"**：替换串必须保留"是"（"大家觉得行业未来方向"语义残缺）。
4. **全局守卫窗口 3→8 风险太大**：影响所有 VOCAB 守卫，回退为仅关注/重视特判。
5. **"用得很广X"缺介词**：需整块替换为"在X用得很广"。
