## v0.5.5 追加：绝对化弱化 + 限制性表述（同类竞品方法论移植，2026-08-17）

### 背景
调研同类降AI攻略（知网/朱雀/腾讯云/笔灵等）发现重复强调的检测原理：
- **困惑度**：AI 爱选高概率词，文本过于可预测
- **语义连贯模式**：AI 段落过渡太丝滑，人类有跳跃
- **词汇分布特征**：AI 偏好特定词汇库（"毫无疑问/必然"等绝对化判断）
- **人类特征**：审慎犹豫、限制性表述（"在一定条件下""多半"）、主观视角、个人痕迹

我们的引擎已有 burstiness/过渡词/让步重构，但缺**绝对化判断弱化**和**限制性表述（hedging）**。

### 改动（全部在 src/engine/humanize.ts）

#### 1. VOCAB 新增绝对化词条（口语化弱化）
| 词 | 替身 | 说明 |
|---|---|---|
| 毫无疑问 | 没跑儿/板上钉钉/明摆着 | 句首绝对化 |
| 必将 | 多半会/十有八九会 | 副词位安全（"多半会带来"通） |
| 必然 | 多半/十有八九 | 状语位（"必然导致"→"多半导致"） |
| 必然的 | 明摆着的/没跑儿的/板上钉钉的 | 词长3优先于"必然"，处理"必然的X" |
| 势在必行 | 非做不可/躲不开/推不掉 | |
| 刻不容缓 | 等不了/拖不起/缓不得 | |
| 不言而喻 | 不用多说/明摆的/不消说 | |

#### 2. replaceTemplates 新增绝对化句式
- 句首：`^(毫无疑问|毋庸置疑|不可否认|显而易见|显然)，X` → "要我说，X/平心而论，X/老实讲，X/说白了，X"
- 句尾：`是(毫无疑问|毋庸置疑|必然|显而易见的)` → "是明摆着的/没跑儿的/板上钉钉的"

#### 3. 新增 hedgeDeterminism 函数（限制性表述）
- 检测强确定性句尾（必然的/毫无疑问的/明摆着的/板上钉钉的/没跑儿的等）
- 概率（0.3×强度）追加犹豫/兜底表述："话虽这么说，也得看具体情况。""不过凡事都有例外。""说到底还是要看实际效果。"等
- 已有犹豫表述（不过/但是/然而/例外/看情况）不叠加
- 只做句尾追加，不插入句中（避免病句）；接入主流程 relaxRedundantVerb 之后

#### 4. 关键 bug 修复（本轮踩坑）
- **GUARD_AFTER["必然"]["的"] 误伤**：8 字窗口把"必然会带来**新的**机遇"里"新的"的"的"也拦了，导致"必然"状语位不替换。移除该守卫——"必然的"已由 VOCAB 独立词条（词长3优先）处理，无需守卫。
- **"必然"替身句法位置**：初版"跑不了/免不了"做状语是病句（"跑不了会带来"❌），改为副词化"多半/十有八九"才通。

## v0.5.6 追加：句中插入语（句法多样性）+ 及物动词完成时态修复（2026-08-17）

### 背景
AI 句式丝滑平铺、句法过于规整是朱雀/知网检测的核心指纹之一。调研确认三类未覆盖特征：句法多样性（倒装/状语前置/插入语）、绝对化词（已补）、hedging（已补）。本轮落地**句中插入语**——中文口语高频的人类特征，人类说话会中途停顿、插入立场/评价，AI 不会。相比纯规则倒装（高病句风险），插入语最安全。

### 改动（全部在 src/engine/humanize.ts）

#### 1. 新增 PARENTHETICALS 常量（11 个轻量插入语）
`说白了/讲真/说实在的/你细品/老实说/客观说/往实了说/不瞒你说/说句实话/平心讲/细琢磨下`（与 INTERJECTIONS 部分重叠但独立成表，便于日后调优）

#### 2. 新增 insertParenthetical 逻辑（接入切句循环）
- 触发：句长 >18 字、含逗号、未插句首垫词（lastWasInterjection=false）、非标点开头、概率 0.16×强度
- 位置：**第一个逗号前**，主语段 4~16 字才插（<4 字插了像"这，说白了，X"主语残缺；>16 字割裂）
- 防病句：已插垫词的句子跳过（双垫词叠罗汉）；插入语计入 usedInterjections 去重
- **执行顺序修正**（本轮踩坑）：初版放在句首垫词之前，导致同一句"句首垫词+句中插入语"叠罗汉（"往实了说，…客观说，…"）。改为**句首垫词之后**——若本句已插句首垫词（lastWasInterjection=true）则跳过插入语。

#### 3. 及物动词完成时态修复（插入语验证中暴露的既有病句）
验证插入语时发现："推动了产业变革"经 VOCAB 替换 + 保留的"了"→"拉着了/推着了/带着了产业变革"❌。

| 词 | 原替身（病） | 新替身 | 修复 |
|---|---|---|---|
| 推动 | 推着/带着 | **带动** | GUARD_AFTER["了"]："推动了"完成时保留原词 |
| 驱动 | 推着/带着/拉动 | **拉动/带动** | GUARD_AFTER["了"] |
| 牵引 | 拉着/带着/拽着 | **拉动/带动** | GUARD_AFTER["了"] |
| 带动 | 拉着/带着/推着 | **拉着走/领着** | GUARD_AFTER["了"] |
| 落地 | 真正做出来/真做出来 | 不变 | GUARD_BEFORE["的"]：名词位（"政策的落地"）不替换 |
| 生态 | 圈子/环境/这块地盘 | **圈子/环境/样貌** | "课堂这块地盘"搭配怪，去"这块地盘" |

根因：VOCAB 纯词替换不感知完成时态后缀"了"——"推动了"→"推动"被替成"拉着"，"了"保留→"拉着了"❌。
修法：给及物动词词条加 GUARD_AFTER["了"]，完成时态整词保留（"推动了"本身是正常书面语，无需去味）。

## v0.5.8 追加：被动语态软化 + 状语前置（句法多样性，2026-08-17 晚）
### 背景
v0.5.7 后句法多样性只剩两个未覆盖维度：被动语态比例（AI 书面腔高频被X所Y/受到X/得到X，检测器抓被动比例）与状语位置单一（AI 主-状-谓平铺，人类偶尔状语前置）。
