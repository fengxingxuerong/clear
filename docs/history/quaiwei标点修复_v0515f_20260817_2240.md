# QuAiWei v0.5.15f 全角/半角标点系统性修复

时间：2026-08-17 22:40
项目：`D:\_冗余归档\workbuddy会话\_portfolio_test_artifacts_20260807\unpacked\quaiwei\quaiwei`
文件：`src/engine/humanize.ts`

## 目标
修复朱雀送检回归：120次14命中[但，]、反指纹100次违规、指纹体检2次漏报。

## 根因
全部是**全角/半角标点不匹配**——历史 edit 工具写入全角字符不稳定（字节层损坏），导致去重/限额/检测逻辑静默失效。

## 修复清单
1. VOCAB `然而` 词条去掉"但"替身（"然而，X"→"但，X"病句）→ `["不过","可是","话是这么说"]`
2. dedupePadWords 垫词去重 `w + ","` → `w + "，"`（全角）
3. limitPunctuation 破折号 mark `"--"` → `"——"`，替换串半角→全角
4. limitPunctuation 省略号 mark `"......"` → `"……"`
5. fingerprintCheck 三处：垫词复读/破折号/省略号 split 全角化

## 验证结果
- scan-bugs 全量回归全绿（120零病句 + 反指纹0违规 + 竞品20 + 体检漏报0 + 审计9 + 忠实度）
- opt-stress 250次 + opt-full-v054 200次压测零病句/零残留
- 朱雀送检 5/8 通过（3个 CV 边界，已知可接受）

## 教训
- 全角字符修复必须走 node 脚本读字节写入（read 显示层转换不可信、edit 写入不稳定）
- 检测/去重/限额逻辑的标点必须与文本实际一致，半角版本静默失效
