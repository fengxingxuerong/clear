# 趣AI味 QuAiWei v0.5.14 — 宏观结构 + 句内节奏 + 序数扩展

## 一、宏观结构方向（语义连贯性）

### 1. 序数词三连补全
- **问题**：OPENERS 只有"第一/第二"，缺"第三/第四/第五" → "第一…第二…第三…"序列不统一（口语混书面）
- **修复**：补 OPENERS["第三/第四/第五"]→ tos 用纯序数连接词（三来/再往下说/四来/五来），避免名词歧义
- **误伤检查**："第三天/第三者/第一线/第二故乡/第一时间" 守卫（charAt(from.length) 检查分隔符）全不误伤 ✓
- "首先/其次/最后"→"头一件/二来/末了" 已口语化（原功能）

### 2. 总结回扣词补全
- **问题**："综上"（书面缩写）→ AI 高频，VOCAB 无条目，漏网
- **修复**：VOCAB 加 `综上: ["总的来看","归根到底","说到底"]`（词长降序，"综上所述"4字优先于"综上"2字，无冲突）
- "总之"保留（口语词，人类也用）

## 二、句内节奏方向（burstiness 句内补充）

### 1. "既能…又能…还能"三连
- **问题**：breakParallelism 只处理"要/在/是"三连，"既能X又能Y还能Z"能力列举指纹漏网
- **修复**：补两类正则（三连 + 两连"既能…也能"）
  ```
  /既能(X)，又能(Y)，还能(Z)/ → ["能X，也Y，Z也不赖","X没问题，Y也行，Z同样能成"]
  /既能(X)，也能(Y)/ → ["能X，也Y","X没问题，Y也行"]
  ```

### 2. 逗号四连打散
- 已有兜底：splitSentences 概率劈句（"提高了效率。降低"）+ 插入语（"…细琢磨下…"）
- 不单独加四连规则（句号劈分足够打散部分节奏，避免新指纹叠加）
