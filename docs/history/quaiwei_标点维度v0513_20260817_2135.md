# 趣AI味 QuAiWei v0.5.13 — 续：标点维度（分号+短句合并bug）

## 一、修复"；，"叠标点病句（关键 bug）

### 根因
切句循环的**短句合并块**：
```js
const prev = out.pop()!;
out.push(prev.replace(/[。！？!?]+$/, "") + "，" + s);
```
`splitSentences` 把分号拼到句尾（"甲；"），prev="甲；"未被处理（只去句号/感叹号），合并时插入逗号 → "甲；，乙。"。

### 修复
合并前先清分号：`prev.replace(/[；]+$/, "，").replace(/[。！？!?]+$/, "")`——前句尾分号→逗号（而非"；，")。

## 二、分号对仗松弛（新功能）

### 背景
AI 高频用分号排比（"A；B；C"），人类很少写分号——检测器结构规律性强信号。

### 新增 relaxSemicolon（probability 0.4×intensity）
- 全角"；" → 概率换"，" / "。" / 保留"；"
- 不全部替换（偶尔保留一分号反而更像人）

### 接入
`working = relaxSemicolon(working, rng, 0.4 * intensity)`（relaxQuotes 之后、splitOnConnectors 之前）

- scan-bugs 全量回归全绿 + opt-stress 250次零病句 + opt-full-v054 200次零病句
