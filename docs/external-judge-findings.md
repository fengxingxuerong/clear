# 外评证据：本地 aiScore 在论说/叙事体裁上严重低报 AI 味

日期：2026-09-22　席位：StepFun `step-3.5-flash`（与写手 SenseNova/DeepSeek 系、合议庭三席均不同系）
复算命令：`npx tsx scripts/external-judge.mjs <含外部访问串的文件> --len 65 --reps 3`
（脚本只按哈希挑"本仓凭证文件里从未出现过的那一条"，不打印、不复制其内容）
打分口径：与 `src/api/llm-judge.ts:32` 同一条 prompt——**分数 = 有多像 AI 写的，100=绝对是 AI，0=绝对是人**。

## 一、为什么要做这一步

竞品对比时我自己写的第一条前提是"自评必然有偏"。而本仓此前的所有"能力"结论都建立在两把
自家尺子上：本地 `aiScore`（纯规则、零成本，UI 上那个分数就是它）和闭环评委（DeepSeek 系模型）。
唯一的第三方真值是朱雀官方分，但 18 个标定点**认证覆盖 0/18**，深度模式更是**零官方真值**。

所以需要一个不属于我们自己模型谱系的外部席位来回答一个问题：**本地分说"已经很像人"的时候，
外面的人看得出来吗？**

## 二、实测结果（对象是 2026-09-20 那轮深度模式留下的全部 5 份交付稿）

`npx tsx scripts/external-judge.mjs <外部访问串文件> --len 65 --reps 3`（分数越高越像 AI）

| 稿件 | 本地 aiScore | 外部席位 | 极差 | 闭环评委当时 |
|---|---|---|---|---|
| 07-政务报告 r1 | **2** | **90** | 0 | — |
| 07-政务报告 r2 | **2** | **90** | 0 | — |
| D0 交付稿（那轮唯一"达标"） | 8 | 15 | 0 | 6 |
| N1 回退稿（LLM 没过质检，回退本地引擎） | 8 | 85~90 | 5 | —（无合格稿） |
| O1 交付稿（跑满 3 轮从未达标） | 13 | 75~80 | 5 | 92→73→88 |

对应原文外评：D0=85、O1=85、N1=90。

**5 份里 4 份本地分 ≤13、外部席位 ≥70，最大分歧 88 分；只有 D0 那一份两边一致（8 / 15）。**
这不是单点事故，是系统性的：本地尺在"政务/论说/叙事"这三类书面体上给出的低分，
在一个不同系的模型眼里几乎不成立。唯一一致的 D0，恰好是内容被腰斩过半的那一篇。


## 三、结论

0. **最刺眼的一条是 07 政务报告**：本地 `aiScore` 给 2（几乎满分的"像人"），外部席位两轮都给 90。
   这个数就是 UI 上给用户看的那个数。它在"报告体"上几乎完全失去了指示意义。
1. **D0 是唯一一把对的尺子量出的真降**：原文 85 → 交付稿 15，外部席位认。但它是靠
   **腰斩一半篇幅**（652→336 字、场景块整行消失、说话人职务标注 4→0）换来的，已由 #30 的
   `structureIssues()` 补进硬闸门。
2. **O1 上本地分在说谎**：本地 13（人写带 `AI_SCORE_HUMAN_MAX=27`），外评 75–80。
   而闭环评委当时给的是 73——**两把不同系的尺子互相印证， outliers 是我们自己那把**。
   此前我把它记成"评委与本地分歧 60 分，是呈现层没显示出来"，那个描述不准确：
   不是分歧需要显示，是**本地分需要被质疑**。
3. **N1 最能说明问题**：本地引擎把 33 降到 8，外评 **90 → 85~90，几乎没动**。
   也就是说规则通道在这篇上做的那次大幅降分，在一个独立席位眼里**没有发生**。
   这正是"指标归零≠修好"的实物版本。

## 四、这把尺子自身的局限（不许略读）

- 单一模型、单一系别。StepFun 自己的检测倾向未知，它可能恰好偏爱/排斥某类文风。
- LLM 当检测器有公认偏差（对自家风格的偏好、对长度的敏感）。**它不是朱雀官方分**，
  不能直接拿来换算"过没过 40% 线"。
- 但它与被评文本的生成模型**不同系**，且三次重复极差 ≤5，所以"O1 本地 13 / 外评 80"这个
  量级的分歧不能用评委抖动解释。
- 反过来，`calibration-data.json` 里的官方真值也已经在自报过时：`npm run test:calib` 报
  **漂移点 6/18**（`D0 Δ-35`、`N1 Δ-14`），只因漂移基线锁在 6/6 才没转红。

## 五、因此改变的做法

1. UI 上那个本地分**只能当相对进度条**，不能当"像人程度"的绝对承诺——它和独立席位的判断
   在论说/叙事上可差 60 分以上。这条写进文档，等能改文案时同步进 README。
2. 深度模式的停止条件不该只看闭环评委；本地分与外部席位分歧过大时应当**显式标注不可信**，
   而不是照常交付（O1 就是照常交付的）。
3. 真正的裁决只来自朱雀官方分 → 任务 #28/#29 的优先级高于任何新增引擎规则。缺的是
   **EdgeOne Makers 那把自己建的凭证**（2026-09-22 拿桌面那份多平台凭证本试过一次：
   里面 6 条分属 AMD/SenseNova×3/NVIDIA/StepFun/OpenRouter，没有一条是 EdgeOne 的；
   拿 StepFun 那条打朱雀网关得到 401。StepFun 通路本身可用，OpenRouter 通路鉴权通过但
   账户从未充值、chat 返回 402）。
