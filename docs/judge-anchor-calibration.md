# glm-5.2 严评锚点问题与评判模型宽严校准

**记录日期**：2026-09-09
**状态**：已确认（本轮闭环实测 + 历史记录交叉印证）
**影响面**：深度闭环达标判定（`humanizeViaApiDeep`）、评判分数解读

## 一、问题陈述

glm-5.2 作为交叉评判模型时存在**系统性严评偏置**：对人工评审确认"人味充足、可过真人审查"的文本仍打高分（60–90 区间），导致：

1. **达标线失真**：绝对目标 10 在严评下永不达标，深度闭环只能靠预算耗尽收场，白烧 API 调用。
2. **分数与质量背离**：评判分无法用于判断真实改写质量，只能靠人工评审兜底。

## 二、实测证据（2026-09-09 真实 API 闭环，修复后引擎）

| 样文 | 本地代理分（前→后） | glm-5.2 评判 | 质检 | 人工评审结论 |
|---|---|---|---|---|
| 01-套话排比 | 72 → 0 | 62 | 通过 | ✅ 可过真人审查 |
| 02-半导体学术（academic） | 76 → 16 | 85 | 有一轮挂 | ✅ 质量最佳 |
| 03-数字经济评论 | 45 → 12 | 90 | 通过 | ✅ 可过真人审查 |

**背离模式**：本地代理分 0–16（极低 AI 味）而 glm-5.2 评 62–90。三篇文本经逐篇人工评审确认语义保真、术语无损、无机器指纹（P1–P6 修复项全部消除）——严评分不构成质量否定证据。

**历史印证**（v0.8.8 注释，2026-09-07 实测）：glm-5.2 对双模型竞争胜出稿仍打 86/91。

## 三、已有缓解机制（v0.8.8 评判锚点放宽）

`src/api/llm-humanize.ts` 的 `RELATIVE_TARGET_RATIO = 0.35`：以首轮正分为宽严锚点，有效达标线 = max(绝对目标, 首轮分 × 0.35)。

- 严评（首轮 86）→ 目标放宽至 ≤31
- 宽评（首轮 45）→ ≤16
- 首轮已低（≤28）→ 维持绝对目标

**局限**：锚点放宽只能防止"白烧预算"，不能让分数恢复判别力——严评下 62 与 90 之间的差异仍主要反映模型偏置而非文本质量。

## 四、宽评模型对照实验（2026-09-09，deepseek-v4-pro 重评三篇闭环稿）

**实验设计**：对三篇闭环最终文本（glm-5.2 已评 62/85/90），用 deepseek-v4-pro 单模型 3 次采样取中位数（temperature=0），调用间冷却 15s 防 TPM 限流。

| 样文 | 采样分 | deepseek-pro 中位数 | glm-5.2 | 宽严差 |
|---|---|---|---|---|
| 01-套话排比 | 60 / 68 / 68 | 68 | 62 | -6（反高） |
| 02-半导体学术 | 75 / 82 / 83 | 82 | 85 | +3 |
| 03-数字经济评论 | 68 / 55 / 84 | 68 | 90 | +22 |

**关键发现（修正此前假设）**：

1. **deepseek-v4-pro 对这批文本同样打高分**（中位数 68–82），并非宽评模型。此前"deepseek 系更宽"的判断来自历史 A/B（glm 改写稿被 deepseek 判 35），样本不同不可直接迁移——**评判宽严是"模型 × 文本类型"的交互，不是模型的固定属性**。
2. **采样方差显著**（03 篇 55↔84，极差 29 分）：单模型 temperature=0 下评判本身不稳定，中位数（3 次）是必要的，单次评分不可作依据。
3. **两模型交叉验证的结论**：三篇人工评审确认可过真人审查的文本，LLM 通用评判（无论 glm 还是 deepseek）都打 60–90——**通用 LLM 评判对"去味后文本"的判别力整体有限**，其高分更多反映"这段文字像被处理过/像 AI 改写"而非"绝对通不过人类审查"。

## 五、校准建议（依据上述实验修订）

1. ~~换用 deepseek 系宽评~~ **已证伪**：宽严不是模型固定属性，换模型不能解决判别力问题。
2. **双模型交叉均值**（`judgeScoreStable` 主+交叉各 1 次取均值）保留：可对冲单模型偏置与采样方差，但两模型都偏高时仍无法恢复判别力。
3. **分数解读纪律（强化）**：LLM 通用评判分只作趋势参考（同一模型对同一文本跨轮次的变化方向），**不作为验收结论**；验收须以质检（qualityCheck）+ 本地指纹体检 + 人工评审三角互证。
4. **锚点放宽机制（v0.8.8）是当前最务实的缓解**：按首轮分自适应放宽达标线，避免严评下白烧预算；本轮实测三篇均在锚点放宽后正常收场。
5. **朱雀语义层**（`zhuque-semantic`）与朱雀真实检测口径对齐，仍是比通用 LLM 评判更接近"过检"的信号源，后续验收优先走该通道。
