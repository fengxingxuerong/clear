  趣AI味 · QuAiWei v0.5.1 使用说明
  中文 AI 文本"去 AI 味"工具（本地引擎离线可用 + 可选 LLM 深度去味）
════════════════════════════════════════════════

【一、这是什么】
把 AI 写的文章改得更像人写的：
  · 本地引擎：纯离线、零成本、原文不出设备（轻度去味，无需任何配置）
  · LLM 深度模式（推荐）：接入 OpenAI 兼容接口后，"改写→评分→自动再改写"
    多轮闭环，去味效果最好（实测同一评判尺下原文 ~90 → 15~35 区间，耗时 2~4 分钟）

【二、桌面文件夹里有什么】
  一键启动.bat        ← 日常用：双击即启动并自动打开浏览器
  环境依赖安装.bat    ← 只在换电脑/重装系统后跑一次：装好 Node 依赖
  使用说明.txt        ← 本文件
  src/ dist/ 等       ← 软件本体，别动

【三、环境要求（仅一项）】
  Node.js 18 或更高版本
  下载：https://nodejs.org/ （选 LTS 版，安装时一路下一步）
  已装过的机器无需重复安装。

【四、启动（一个 bat 搞定）】
  1. 双击「一键启动.bat」
     - 依赖未装会自动安装（约 1~2 分钟，只需一次）
     - 之后自动打开浏览器 http://localhost:5173
  2. 使用期间保留弹出的「QuAiWei 服务」窗口；关闭它即停止服务

  手动方式（等效）：
     npm install
     npm run dev        # 然后浏览器打开 http://localhost:5173

【五、配置 LLM（可选，但强烈推荐）】
  界面右上角「设置」：
  · 启用 API：勾选
  · Base URL / API Key / 模型：填你的 OpenAI 兼容服务商
  · 深度模式：默认已开启（主界面"去味"按钮旁有"深度模式"标记）

  ┌─ 商汤 SenseNova 用户专用填法（本机开发模式已内置代理）─────────┐
  │  Base URL：/sensenova/v1                                        │
  │  模型：    glm-5.2（改写最强，交叉评判实测 35 vs 75 分）
  │            或 deepseek-v4-flash（最快，1.7~2.3s）                │
  │  其他模型：sensenova-6.8-flash-lite（可用但较慢）                 │
  │            sensenova-u1-fast（当前 404，不可用）                  │
  └──────────────────────────────────────────────────────────────────┘
  注意：SenseNova 的 CORS 预检有坑，"/sensenova/v1" 这个相对地址只在
  「一键启动.bat」（vite 开发服务）下有效。静态托管/Electron 桌面版里
  请换 CORS 放行的服务商（如 OpenAI），或自建反向代理。

【六、去味强度怎么选 & 指纹体检】
  重要文稿送检朱雀前，点对标区的"指纹体检（本地）"按钮自查：空格指纹、垫词复读、套话残留、句长节奏等 7 项红项会被点名，零成本秒出。
  · 没配 API：拖"去味强度"滑块，本地引擎处理（0.6 起步）
  · 配了 API：滑块不起作用，由深度模式接管（最多 4 轮（中位数评分），每轮实时显示
    LLM 评分，达标 ≤10 分自动收手，最终保留最低分版本）

【七、送检朱雀的注意事项】
  · 朱雀要求文本 ≥350 字（界面会自动提示当前字数）
  · 未登录有次数限制，高峰期匿名请求易"服务超时"，建议错峰或登录
  · 本工具评分≠朱雀官方分，发布/交稿前请自行送检验证

【八、常见问题】
  Q: 双击 bat 闪退？
  A: 多半是没装 Node.js，或被杀毒软件拦截。装好 Node 后重试。

  Q: 端口被占用（5173）？
  A: 关掉旧的"QuAiWei 服务"窗口；或任务管理器结束残留 node.exe。

  Q: 改了代码但页面没变化？
  A: 项目路径含中文/括号时 vite 热更新可能失灵，重启一键启动即可。

  Q: "API 调用失败，已回退本地引擎"？
  A: 检查 Key 是否有效、Base URL 是否按第五节填写、网络是否可达。
     SenseNova 偶发空回复（思考型模型 token 预算问题），重试即可。

【九、桌面版（可选）】
  electron-app/ 已含最新 Web 构建。打包 Windows 版：
     cd electron-app
     npm install
     npx electron-packager . QuAiWei --platform=win32 --arch=x64 --out=../electron-dist
  （需下载 Electron 运行时，体积较大，仅在需要 exe 时操作）

【十、隐私】
  · 本地引擎：原文只在你设备上处理，不联网
  · API 模式：原文会发给你自己配置的服务商；Key 仅存浏览器本地
  · 本工具不收集任何数据
